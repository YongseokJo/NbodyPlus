# Plan 24-01: Batched Queue Infrastructure

## Objective

Create the BatchedQueue data structure and MPI type registration needed for message batching.

## Context

Current system sends one Queue per MPI message. This plan creates a new BatchedQueue structure that can hold multiple particle IDs in a single message, reducing MPI message count by up to 100x.

## Tasks

<task id="1">
Add BatchedQueue struct to queue.h

Add after the existing Queue struct:

```cpp
// ============================================================================
// Batched Queue structure for MPI optimization (Phase 24)
// ============================================================================
constexpr int MAX_BATCH_SIZE = 100;  // Maximum particles per batch

struct BatchedQueue {
    task_name_t task;                   // Task type (all particles share same task)
    int count;                          // Number of particles in this batch (1 to MAX_BATCH_SIZE)
    int pids[MAX_BATCH_SIZE];           // Particle IDs
    double next_time;                   // Next time (for irregular tasks)

    void print() {
        std::cout << "BatchedQueue: task=" << static_cast<int>(task)
                  << ", count=" << count
                  << ", next_time=" << next_time << std::endl;
        for (int i = 0; i < count; i++) {
            std::cout << "  pids[" << i << "]=" << pids[i] << std::endl;
        }
    }
};
```
</task>

<task id="3">
Define batch_size global variable and register BatchedQueue MPI type

In src/mpi_types.cpp (or equivalent initialization file), add:

```cpp
// Phase 24: Batch size configuration
int batch_size = 50;  // Default batch size

// Phase 24: BatchedQueue MPI type
MPI_Datatype batched_queue_type_mpi;

void register_batched_queue_type() {
    // BatchedQueue structure layout:
    // - task_name_t task (int8_t, 1 byte)
    // - int count (4 bytes)
    // - int pids[MAX_BATCH_SIZE] (MAX_BATCH_SIZE * 4 bytes)
    // - double next_time (8 bytes)

    int blocklengths[4] = {1, 1, MAX_BATCH_SIZE, 1};
    MPI_Datatype types[4] = {MPI_INT8_T, MPI_INT, MPI_INT, MPI_DOUBLE};
    MPI_Aint offsets[4];

    offsets[0] = offsetof(BatchedQueue, task);
    offsets[1] = offsetof(BatchedQueue, count);
    offsets[2] = offsetof(BatchedQueue, pids);
    offsets[3] = offsetof(BatchedQueue, next_time);

    MPI_Type_create_struct(4, blocklengths, offsets, types, &batched_queue_type_mpi);
    MPI_Type_commit(&batched_queue_type_mpi);
}
```

Call `register_batched_queue_type()` from MPI initialization (where queue_type_mpi is registered).
</task>
