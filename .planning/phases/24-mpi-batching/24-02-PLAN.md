# Plan 24-02: Root-Side Batch Dispatch

## Objective

Modify the QueueScheduler to accumulate tasks and send them in batches instead of one at a time.

## Context

Currently `assignQueueAuto()` assigns one particle per free worker. This plan modifies it to:
1. Accumulate particles in a batch buffer
2. Send a full BatchedQueue when a worker is free
3. Handle partial batches at end of queue

## Tasks

Add batch state to QueueScheduler

```cpp
private:
    // Phase 24: Batch dispatch state
    BatchedQueue _pending_batch;      // Current batch being built
    bool _batching_enabled;           // Whether to use batching (default: true)

    // Phase 24: Fill batch from queue_list
    int _fillBatch() {
        _pending_batch.count = 0;
        _pending_batch.task = _task;
        _pending_batch.next_time = _next_time;

        while (_pending_batch.count < batch_size && _queue_list.size() > 0) {
            _pending_batch.pids[_pending_batch.count++] = _queue_list.back();
            _queue_list.pop_back();
        }
        return _pending_batch.count;
    }
```

<task id="3">
Create batched assignment method

Add new method `assignBatchAuto()` to QueueScheduler:

```cpp
// Phase 24: Batched assignment
void assignBatchAuto() {
    PROFILE_START(TimerID::QueueAssign);
    if (_queue_list.size() == 0) {
        PROFILE_STOP(TimerID::QueueAssign);
        return;
    }

    // Phase 16: Sample queue depth before assignment
    PROFILE_QUEUE_DEPTH(static_cast<int>(_queue_list.size()));

    for (auto worker = _FreeWorkers.begin(); worker != _FreeWorkers.end();) {
        if (_queue_list.size() > 0 && (*worker)->NumberOfQueues == 0) {
            // Fill a batch
            int count = _fillBatch();
            if (count == 0) break;

            // Track assigned
            _assigned_queues += count;

            // Add to worker and mark for dispatch
            (*worker)->add_batch(_pending_batch);
            WorkersToGo.insert(*worker);

            PROFILE_WORKER_ASSIGNMENT((*worker)->MyRank);
            worker = _FreeWorkers.erase(worker);
        } else {
            ++worker;
        }
    }
    PROFILE_STOP(TimerID::QueueAssign);
}
```
</task>

<task id="4">
Add batch queue storage to Worker

In `src/worker.h`, add batch queue support:

```cpp
// Phase 24: Batched queue storage
BatchedQueue pending_batches[MAX_QUEUE];
short num_batches;
short current_batch;

void add_batch(BatchedQueue& batch) {
    int index = (current_batch + num_batches++) % MAX_QUEUE;
    if (num_batches >= MAX_QUEUE) {
        fprintf(stderr, "num_batches exceeds MAX_QUEUE!\n");
        exit(EXIT_FAILURE);
    }
    pending_batches[index] = batch;
}

void run_batch() {
    if (on_duty) {
        std::cerr << "Worker " << rank << " already on duty" << std::endl;
        exit(1);
    }
    if (num_batches == 0) {
        fprintf(stderr, "No batch to run!\n");
        exit(EXIT_FAILURE);
    }
    send_batch(pending_batches[current_batch]);
}
```

Initialize in `initialize()`:

Add `runBatchAuto()` to QueueScheduler:

```cpp
void runBatchAuto() {
    PROFILE_START(TimerID::QueueRun);
    for (auto worker = WorkersToGo.begin(); worker != WorkersToGo.end();) {
        if ((*worker)->num_batches > 0 && !(*worker)->onDuty) {
            (*worker)->run_batch();
            worker = WorkersToGo.erase(worker);
        } else {
            ++worker;
        }
    }
    PROFILE_STOP(TimerID::QueueRun);
}
```

Update callback for batch completion

Modify Worker::callback() in `src/worker.h` to handle batch counts:

```cpp
void batch_callback() {
    int return_count;
    PROFILE_START(TimerID::MPIRecv);
    MPI_Recv(&return_count, 1, MPI_INT, this->rank, TERMINATE_TAG, MPI_COMM_WORLD, &_status);
    PROFILE_STOP(TimerID::MPIRecv);
    if (!on_duty) {
        fprintf(stderr, "Error: worker %d was not on duty.\n", this->rank);
        exit(1);
    }
    on_duty = false;
    current_batch++;
    current_batch %= MAX_QUEUE;
    num_batches--;
}
```

Update QueueScheduler::callback() to handle batch counts:

```cpp
void batch_callback(Worker* worker) {
    PROFILE_START(TimerID::QueueCallback);
    int batch_count = worker->pending_batches[worker->current_batch].count;
    worker->batch_callback();
    _completed_queues += batch_count;  // Count all particles in batch

    // Phase 16: Sample queue depth at task completion
    int remaining = static_cast<int>(_queue_list.size() + _queue_list_.size());
    PROFILE_QUEUE_DEPTH(remaining);

    if (worker->num_batches > 0)
        WorkersToGo.insert(worker);
    else
        _FreeWorkers.insert(worker);
    PROFILE_STOP(TimerID::QueueCallback);
}
```
