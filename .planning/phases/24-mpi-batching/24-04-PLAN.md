# Plan 24-04: Batch Integration and Tuning

## Objective

Integrate batched dispatch into the main simulation loops (IrregularRoutines, RegularRoutines) and tune batch_size for optimal performance.

## Context

Plans 24-01 through 24-03 created the infrastructure. This plan:
1. Switches the main dispatch loops to use batched methods
2. Tests with different batch_size values
3. Verifies correctness and measures speedup

## Tasks

<task id="1">
Modify IrregularRoutines to use batched dispatch

In `src/irregular_routines.cpp`, replace single-dispatch loop with batched:

**Current (around line 165-207):**
```cpp
do {
    queue_scheduler.assignQueueAuto();
    queue_scheduler.runQueueAuto();
    do {
        worker = queue_scheduler.waitQueue(1);
        // CM particle handling...
    } while (worker == nullptr);
    queue_scheduler.callback(worker);
} while (queue_scheduler.isComplete());
```

**New (batched for regular particles, single for CM):**
```cpp
do {
    // Phase 24: Use batched dispatch for regular particles
    queue_scheduler.assignBatchAuto();
    queue_scheduler.runBatchAuto();

    do {
        worker = queue_scheduler.waitQueue(1);

        // CM particle handling stays single-dispatch
        if (queue_scheduler.CMPtcls.size() > 0) {
            // ... existing CM particle code unchanged ...
        }

    } while (worker == nullptr);

    // Phase 24: Use batch callback
    queue_scheduler.batch_callback(worker);

} while (queue_scheduler.isComplete());
```

Note: CM particles (TASK_AR_INTEGRATION) still use single dispatch via the existing code path.
</task>
