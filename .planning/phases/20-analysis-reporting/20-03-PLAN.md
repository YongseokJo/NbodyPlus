# Plan 20-03: Generate Final Analysis Report

## Goal

Run the analysis script on actual profiling data and generate the final ANALYSIS.md report documenting findings and v2.3 recommendations.

## Requirements Addressed

- **ANLYS-04**: Produce analysis report with optimization recommendations

## Prerequisites

- Plan 20-01 executed (worker histogram added)
- Plan 20-02 executed (analysis script enhanced)
- Profiling data from test simulation available

## Steps

### 1. Run Test Simulation with Profiling

Run test4 simulation to generate profiling data with all Phase 15-19 metrics:

```bash
cd tests/test4
./run_test.sh
```

Or if profiling.csv already exists from previous runs, skip to step 2.

### 2. Run Analysis Script

Generate the analysis report:

```bash
python tools/analyze_profiling.py tests/test4/output/profiling.csv \
    --report .planning/phases/20-analysis-reporting/ANALYSIS.md
```

### 3. Review and Finalize Report

The generated report will be in `.planning/phases/20-analysis-reporting/ANALYSIS.md`.

If manual adjustments are needed based on domain knowledge, edit the report to:
- Add specific particle IDs if heavy particles identified
- Include any test-specific observations
- Refine recommendations based on ABYSS architecture

### 4. Update Milestone Documentation

After report is finalized:

1. Update STATE.md to mark Phase 20 complete
2. Update ROADMAP.md Phase 20 status to "Complete"
3. Update REQUIREMENTS.md to mark ANLYS-01 through ANLYS-04 as complete
4. Update v2.2 milestone Definition of Done checklist

## Expected Output

The ANALYSIS.md report will contain:

1. **Summary**
   - Total wall-clock time
   - Simulation time range
   - Number of intervals analyzed

2. **Top Imbalance Sources** (ranked by severity)
   - Source name and severity (HIGH/MEDIUM)
   - Quantitative metric
   - Specific recommendation

3. **v2.3 Optimization Recommendations**
   - Primary approach based on top finding
   - Numbered action items
   - Expected impact

## Verification

1. ANALYSIS.md exists in `.planning/phases/20-analysis-reporting/`
2. Report contains all required sections
3. Top 3 imbalance sources identified with metrics
4. v2.3 recommendations are actionable
5. STATE.md shows Phase 20 complete
6. v2.2 milestone marked complete
