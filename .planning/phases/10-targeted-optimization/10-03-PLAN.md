## Objective

Validate the optimization by running a profiled simulation, comparing before/after performance, and verifying energy conservation. This completes requirements OPT-01, OPT-02, and OPT-03.

## Context

Plans 10-01 and 10-02 implemented AVX-512 vectorized force calculation in `compute_acceleration_irr()`. Now we need to:
1. Run a full profiled simulation (same as Phase 9 baseline)
2. Compare IrregularForce timing to Phase 9 baseline (69.5 seconds, 53.5%)
3. Verify energy conservation (dE/E0 < 1e-4)

**Phase 9 Baseline:**
- Test case: test1, 0 → 1.0 Myr, 10 output intervals
- IrregularForce: 69.5 seconds average per interval (53.5% of wall time)
- Total wall time: ~130 seconds per interval

**Target:**
- At least 20% improvement in IrregularForce time
- Energy conservation within 1e-4 tolerance

## Tasks

<task id="1">
Run profiled simulation using the workflow:

```bash
cd workflow
./bin/run.sh phase10_validation --test test1 --time 1.0 --trace
```

Wait for simulation to complete. This requires a SLURM job and human execution.
</task>

<task id="2">
After simulation completes, collect profiling data:

1. Locate the profiling CSV:
   ```bash
   ls -la workflow/runs/phase10_validation*/work/output/profiling.csv
   ```

2. Extract IrregularForce timing:
   ```bash
   # Get average IrregularForce time across intervals
   cat workflow/runs/phase10_validation*/work/output/profiling.csv | \
     grep IrregularForce | awk -F',' '{sum+=$2; count++} END {print "Avg:", sum/count, "seconds"}'
   ```

3. Compare to baseline:
   - Baseline: 69.5 seconds
   - Target: < 55.6 seconds (20% improvement)
</task>

<task id="3">
Verify energy conservation:

1. Run energy analysis:
   ```bash
   python3 tools/analyze_energy.py workflow/runs/phase10_validation*/work/output/
   ```

2. Check that dE/E0 < 1e-4

3. Compare to Phase 9 baseline (dE/E0 = 2.52e-5 typically)
</task>
