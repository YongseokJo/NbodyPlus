## Objective

Create an AVX-512 vectorized force calculation module with pre-gather helper and vectorized force kernel. This is a standalone module that can be unit tested before integration.

## Context

Phase 9 identified that IrregularForce takes 53.5% of wall time. The research identified that the neighbor loop in `compute_acceleration_irr()` is the hot path. The loop structure prevents compiler auto-vectorization due to indirect array access, branches, and scattered data.

This plan creates the vectorized force infrastructure. Plan 10-02 will integrate it into the main code path.

## Tasks

<task id="1">
Create `src/simd_force.h` header with:

1. Include guards and required headers (`<immintrin.h>` for AVX-512)
2. `#ifdef __AVX512F__` guard for AVX-512 code
3. Struct `NeighborBatch` for pre-gathered neighbor data:
   - Aligned arrays (alignas(64)) for pos_x, pos_y, pos_z, vel_x, vel_y, vel_z, mass
   - `count` field for number of active neighbors in batch
   - Batch size constant (e.g., 256 neighbors max)
4. Function declarations:
   - `void gather_neighbor_data(...)` - Pre-gather neighbor positions/velocities into aligned buffers
   - `void compute_force_avx512(...)` - Vectorized force accumulation
   - `void compute_force_scalar(...)` - Scalar fallback for systems without AVX-512
5. Include the free function `predict_second_order()` declaration if not already accessible

Reference the patterns from 10-RESEARCH.md for API design.
</task>

<task id="2">
Create `src/simd_force.cpp` implementation with:

1. `gather_neighbor_data()` implementation:
   - Takes: particle array, neighbor indices array, offset, count, prediction dt
   - Iterates through neighbors, skips inactive particles
   - Calls predict_particle_second_order() for each active neighbor
   - Stores predicted pos/vel and mass into NeighborBatch aligned arrays
   - Returns count of active neighbors gathered

2. `compute_force_avx512()` implementation (inside `#ifdef __AVX512F__`):
   - Takes: target particle pos/vel, NeighborBatch, output a[3] and adot[3]
   - Implements vectorized force loop processing 8 neighbors at a time
   - Uses _mm512 intrinsics for all operations
   - Uses rsqrt approximation with Newton-Raphson refinement for r^(-3)
   - Handles remainder (count not multiple of 8) with masked operations or scalar fallback
   - Accumulates into output arrays

3. `compute_force_scalar()` implementation:
   - Same interface as AVX-512 version
   - Standard scalar loop for fallback
   - Used when AVX-512 not available

Use the reference code patterns from 10-RESEARCH.md as starting point.
</task>

## Notes

- The NeighborBatch should use `alignas(64)` for AVX-512 alignment
- Use `_mm512_rsqrt14_pd` for fast inverse square root approximation
- One Newton-Raphson iteration should provide sufficient precision for double
- The vectorized kernel processes 8 doubles per iteration (512 bits)
- Handle edge cases: empty neighbor list, fewer than 8 neighbors
