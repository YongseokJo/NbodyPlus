<objective>
Fix unit conversion in `transformMclusterOutput()` to convert McLuster astrophysical units (Msun, pc, km/s) to ABYSS expected input units (1e-9 Msun, kpc, km/s).

Purpose: McLuster-generated IC files must have correct units for ABYSS's `normalize_particle()` function to produce valid code units. Without this fix, positions would be 1000x too large and masses 1e9x too large, causing incorrect physics simulation.

Output: Updated `transformMclusterOutput()` function with proper unit conversion and documentation.
</objective>
