## Objective

Run a representative simulation with the enhanced profiler (Phase 8) to collect timing data across all components.

## Context

Phase 8 added comprehensive profiling infrastructure:
- Per-rank MPI statistics (min/avg/max)
- Irregular force sub-timers (NeighborLoop, CMLoop, Correction, Predict)
- Worker-side timing (RecvWait, TaskDispatch, SendComplete)
- Queue scheduler timing (Assign, Run, Callback)
- Load balance metrics and warnings

This plan executes a profiled simulation to collect the data needed for analysis.

<task id="1">

</verification>
</task>

<task id="2">
<title>Build with profiling enabled</title>
<type>build</type>
<action>
Run the build script to compile with profiling:
```bash
./build.sh --slurm --test
```
Ensure build completes successfully with profiler code included.
</action>
<verification>
- `src/abyss.exe` exists and is recent
- Build log shows no profiler-related errors
</verification>
</task>

<task id="3">
<title>Run profiled simulation</title>
<type>execution</type>
<action>
Submit a simulation job using test1 configuration:
```bash
cd tests/test1
sbatch ../../workflow/templates/slurm.sbatch.in
```

Or run directly if resources available:
```bash
srun -n 16 ../../src/abyss.exe -c config.toml
```

The simulation runs with:
- 16 MPI ranks (per workflow/config.sh)
- GPU acceleration enabled
- Profiler output at each dtOutput interval (1.0e6 years)
</action>
<verification>
- Job completes successfully
- Output directory created: `tests/test1/output/`
- Console log contains "Aggregated Performance Summary" sections
</verification>
</task>

<task id="4">
<title>Collect profiling output</title>
<type>collection</type>
<action>
After simulation completes, collect:
1. Slurm output log (contains console profiler output)
2. `tests/test1/output/profiling.csv` (if generated)
3. Any `profiling_*.json` files

Save the console output to a file for analysis:
```bash
cp slurm-*.out tests/test1/profiling_output.log
```
</action>
<verification>
- Profiling log captured
- Contains timing breakdown with min/avg/max columns
- Contains load balance analysis section
</verification>
</task>
