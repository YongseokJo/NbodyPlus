## Objective

Add profiler instrumentation to measure overlap effectiveness - how much useful local work is done during the async communication window.

## Context

Phase 11 added async MPI timers:
- `TimerID::MPIIsend` - Time in MPI_Isend calls
- `TimerID::MPIIrecv` - Time in MPI_Irecv calls
- `TimerID::MPIWaitany` - Time in MPI_Waitany calls
- `TimerID::MPITestany` - Time in MPI_Testany calls

To measure overlap effectiveness, we need to track:
1. **Async window duration**: Time between last send and first completion
2. **Local work during window**: Time spent on CM particle iteration
3. **Testany attempts**: Number of non-blocking tests before completion
4. **Overlap ratio**: (local work time) / (async window time)

<task id="2">
Add overlap instrumentation to FEWBODY force loop

In `src/irregular_routines.cpp`, add timing around the async window:

```cpp
        queue_scheduler.postAllReceives();

        do {
            queue_scheduler.assignQueueAuto();
            queue_scheduler.runQueueAsync();

            // Start async window timer (Phase 12)
            PROFILE_START(TimerID::AsyncWindow);
            int testany_attempts = 0;

            do {
                worker = queue_scheduler.testQueueAsync();
                testany_attempts++;

                // Local work: CM particle iteration
                if (queue_scheduler.CMPtcls.size() > 0)
                {
                    PROFILE_START(TimerID::OverlapWork);

                    if (iter == queue_scheduler.CMPtcls.end())
                        iter = queue_scheduler.CMPtcls.begin();
                    cm_pid = *(iter);
                    ptcl = &particles[cm_pid];
                    queue.task = TASK_AR_INTEGRATION;
                    queue.pid = cm_pid;
                    queue.next_time = next_time;
                    workers[cm_particle_worker_map[cm_pid]].add_queue(queue);
                    queue_scheduler.assignWorker(&workers[cm_particle_worker_map[cm_pid]]);
                    iter = queue_scheduler.CMPtcls.erase(iter);
#ifdef SEVN_BINARY
                    if (ptcl->binary_evolution != nullptr)
                        CMPtclsForSEVN.push_back(cm_pid);
#endif
                    PROFILE_STOP(TimerID::OverlapWork);
                }

                if (worker != nullptr)
                {
                    queue_scheduler.callbackAsync(worker);
                }
            } while (worker == nullptr);

            // Stop async window timer (Phase 12)
            PROFILE_STOP(TimerID::AsyncWindow);

#ifdef DEBUG
            fprintf(stdout, "(ASYNC_METRICS) Window took %d testany attempts\n", testany_attempts);
#endif

        } while (queue_scheduler.isComplete());
```
</task>
