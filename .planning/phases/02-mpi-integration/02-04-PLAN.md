# Plan 02-04: Verify MPI Window Creation and Cross-Rank Access

## Objective

Add verification code to confirm that all 66 MPI windows are created successfully and that workers can access data written by root. This validates MPI-01, MPI-02, and MPI-03 requirements.

## Tasks

<task id="1">
Add window creation timing in `initializeMPI()`:
```cpp
double start_time = MPI_Wtime();
particle_data.allocate_shared(MAX_NUM_PARTICLE, shared_comm);
double alloc_time = MPI_Wtime() - start_time;

if (my_rank == ROOT) {
    fprintf(stdout, "ParticleDataMPI: Allocated %zu windows in %.3f seconds\n",
            66, alloc_time);
}
```
This addresses Pitfall #6 (MPI window explosion monitoring).
</task>

<task id="2">
Add verification test after allocation. Create a test function or add inline:
```cpp
// Root writes test values
if (my_rank == ROOT) {
    particle_data.set_pos_x(0, 1.234);
    particle_data.set_mass(0, 5.678);
    particle_data.set_pid(0, 42);
}

// Sync
particle_data.sync_all();

// All ranks verify
double test_pos = particle_data.get_pos_x(0);
double test_mass = particle_data.get_mass(0);
int test_pid = particle_data.get_pid(0);

if (test_pos != 1.234 || test_mass != 5.678 || test_pid != 42) {
    fprintf(stderr, "Rank %d: MPI shared memory verification FAILED\n", my_rank);
    MPI_Abort(MPI_COMM_WORLD, 1);
}

if (my_rank == ROOT) {
    fprintf(stdout, "ParticleDataMPI: Cross-rank access verified\n");
}
```
</task>

<task id="3">
Wrap verification in `#ifdef DEBUG_MPI` or similar so it can be disabled in production builds.
</task>

<task id="4">
Run a test compilation and basic MPI run (2 processes minimum) to verify:
- Window allocation completes
- Timing is reported
- Cross-rank access works
</task>

## Verification Criteria

- [ ] Allocation time is printed (monitors window explosion concern)
- [ ] Test values written by root are readable by workers
- [ ] No MPI errors during allocation or sync
- [ ] Verification can be disabled for production

## must_haves

- Window creation time measured and reported
- Cross-rank data access verified programmatically
- Allocation time under 1 second (acceptable for 66 windows)

This plan is marked `autonomous: false` because it may require manual testing with `mpirun` or cluster job submission. The executor should compile and provide instructions for running the verification.
