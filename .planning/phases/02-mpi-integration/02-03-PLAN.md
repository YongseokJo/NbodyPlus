# Plan 02-03: Wire ParticleDataMPI into MPI Initialization

## Objective

Replace the old `Particle* particles` MPI shared memory allocation with the new `ParticleDataMPI` allocation in `initializeMPI()`. This connects the SoA container to the MPI shared memory system.

## Tasks

<task id="1">
Update `src/global.h`:
- Add `#include "particle_data_mpi.h"`
- Add `extern ParticleDataMPI particle_data;` declaration
- Keep existing `extern MPI_Win win;` and `extern Particle* particles;` for now (temporary coexistence)
</task>

<task id="2">
Update `src/default_global.cpp`:
- Add `ParticleDataMPI particle_data;` definition
</task>

<task id="3">
Update `src/mpi_routines.cpp` `initializeMPI()`:
After the shared_comm is created (line 40), add:
```cpp
// Allocate SoA particle data via MPI shared memory
particle_data.allocate_shared(MAX_NUM_PARTICLE, shared_comm);
```
Keep the existing `win`, `win2`, `win3`, `win4` allocations for now (particles, g_state, neighbors, new_neighbors) as other code still uses them.
</task>

<task id="4">
Update `ParticleSynchronization()` in `src/mpi_routines.cpp`:
After the existing `MPI_Win_sync(win)`, add:
```cpp
// Sync SoA particle data
particle_data.sync_all();
```
This ensures both old and new data structures are synchronized during the transition period.
</task>

<task id="5">
Add MPI finalization cleanup. Find where MPI_Finalize is called (likely in main.cpp) and add before it:
```cpp
particle_data.deallocate_shared();
```
</task>

## Verification Criteria

- [ ] Code compiles with no errors
- [ ] `particle_data` is allocated during MPI initialization
- [ ] Both old `particles` and new `particle_data` coexist
- [ ] `particle_data.sync_all()` called during synchronization
- [ ] Clean deallocation before MPI_Finalize

- Synchronization includes new SoA windows
