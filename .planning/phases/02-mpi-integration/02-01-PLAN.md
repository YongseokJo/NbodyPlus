# Plan 02-01: Create ParticleDataMPI Header

## Objective

Create the `ParticleDataMPI` class header that extends `ParticleData` with MPI shared memory window management. This plan focuses on the class declaration; implementation follows in Plan 02-02.

## Tasks

<task id="1">
Create `src/particle_data_mpi.h` with:
- Include guards
- Include `particle_data.h` and `<mpi.h>`
- Class declaration inheriting from `ParticleData`
</task>

<task id="2">
Add MPI window member arrays to store handles for all 66 SoA arrays:
- `MPI_Win win_pos_[3]` for position arrays
- `MPI_Win win_vel_[3]` for velocity arrays
- `MPI_Win win_mass_` for mass
- `MPI_Win win_acc_total_[3][4]` for total acceleration (12 windows)
- `MPI_Win win_acc_reg_[3][4]` for regular acceleration (12 windows)
- `MPI_Win win_acc_irr_[3][4]` for irregular acceleration (12 windows)
- `MPI_Win win_new_pos_[3]` for new position
- `MPI_Win win_new_vel_[3]` for new velocity
- `MPI_Win win_neighbor_radius_sq_` (1 window)
- `MPI_Win win_timestep_[4]` for timestep doubles (current_time_irr, current_time_reg, time_step_irr, time_step_reg)
- `MPI_Win win_block_[6]` for block time ull_t arrays
- `MPI_Win win_neighbor_int_[3]` for neighbor int arrays
- `MPI_Win win_id_[3]` for ID/index int arrays
- `MPI_Win win_time_level_[2]` for time level ints
- `MPI_Win win_flag_[3]` for bool flag arrays
- `MPI_Win win_other_double_[2]` for radius, delta_mass
</task>

<task id="3">
Add MPI communicator member:
- `MPI_Comm shared_comm_` to store the shared memory communicator
</task>

<task id="4">
Declare public methods:
- `void allocate_shared(size_t capacity, MPI_Comm comm)` — allocate via MPI shared memory
- `void deallocate_shared()` — free all MPI windows
- `void sync_all()` — synchronize all windows
- `bool is_shared() const` — check if using shared memory
</task>

<task id="5">
Declare private helper methods:
- `void allocate_double_array_shared(double** ptr, MPI_Win* win, size_t capacity)` — helper for double arrays
- `void allocate_ull_array_shared(ull_t** ptr, MPI_Win* win, size_t capacity)` — helper for ull_t arrays
- `void allocate_int_array_shared(int** ptr, MPI_Win* win, size_t capacity)` — helper for int arrays
- `void allocate_bool_array_shared(bool** ptr, MPI_Win* win, size_t capacity)` — helper for bool arrays
</task>

## Verification Criteria

- [ ] File compiles with `#include "particle_data_mpi.h"` (no syntax errors)
- [ ] All 66 MPI_Win handles are declared
- [ ] Class inherits from ParticleData
- [ ] allocate_shared(), deallocate_shared(), sync_all() declared

## must_haves

- ParticleDataMPI class exists and inherits from ParticleData
- Window handles for all 66 arrays declared as members
- allocate_shared() method signature matches research pattern
