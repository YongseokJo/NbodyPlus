## Objective

Consolidate the numerous PROFILE_* macros down to essential ones:
- PROFILE_START / PROFILE_STOP (basic timing)
- PROFILE_SCOPE (RAII scoped timing)
- PROFILE_NEIGHBOR_TIME (specialized for neighbor profiling)

Remove unused or redundant macros.

<task id="3">

For removed macros, also remove supporting methods if no longer needed.
</task>

<task id="4">
**Update call sites**

Search for any call sites using removed macros and update:
```bash

```

Replace with appropriate alternatives or remove if functionality is no longer needed.
</task>

<task id="5">
**Ensure PERFORMANCETRACE guards are consistent**

All PROFILE_* macros should:
1. Be no-ops when PERFORMANCETRACE is not defined
2. Have consistent guard structure:
```cpp
#ifdef PERFORMANCETRACE
#define PROFILE_START(id) Profiler::instance().start(id)
#else
#define PROFILE_START(id) ((void)0)
#endif
```
</task>
