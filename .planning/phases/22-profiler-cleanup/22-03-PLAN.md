## Objective

Clean up the JSON profiling output to:
1. Add schema_version field
2. Only output non-zero timers (plus explicitly enabled ones)
3. Support two verbosity modes (simplified default, verbose with flag)
4. Add optional summary section with key metrics

## Tasks

<task id="1">
**Add schema_version and summary to JSON**

In `Profiler::writeJSON()`, add at the start of JSON output:
```json
{
  "schema_version": "2.3",
  "summary": {
    "step": 10,
    "sim_time_myr": 10.0,
    "wall_time_s": 36.0,
    "throughput_particles_per_s": 69000,
    "primary_bottleneck": "MPI dispatch",
    "load_balance_ratio": 1.19
  },
  ...
}
```

Calculate summary metrics from existing data:
- wall_time_s: from WholeRoutine timer
- throughput: from particle counts / wall time
- primary_bottleneck: identify highest non-compute timer
- load_balance_ratio: from worker_distribution
</task>

<task id="2">
**Add verbosity flag to Profiler**

Add member variable and setter:
```cpp
bool verbose_output_ = false;

void setVerboseOutput(bool verbose) { verbose_output_ = verbose; }
bool isVerboseOutput() const { return verbose_output_; }
```

Modify `writeJSON()` to check verbosity:
- **Simplified (default):** Only interval_ns, count, mean_ns per timer
- **Verbose:** All 7 fields (total_ns, interval_ns, count, interval_count, min_ns, max_ns, mean_ns)
</task>

<task id="3">
**Filter zero timers from output**

In the timers section of `writeJSON()`:
```cpp
// Only output timers with non-zero interval data
for (int i = 0; i < static_cast<int>(TimerID::NUM_TIMERS); ++i) {
    const auto& s = stats_[i];
    // Skip if zero interval data (unless explicitly marked always-output)
    if (s.interval_total_ns == 0 && s.interval_count == 0) {
        continue;
    }
    // Output timer...
}
```

This automatically filters out disabled/unused timers.
</task>
