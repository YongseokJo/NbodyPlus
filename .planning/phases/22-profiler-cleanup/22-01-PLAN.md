## Objective

Clean up the TimerID enum by removing completely unused timers, disabling always-zero timers via #ifdef, and renaming RegularForce to RegularCPU for clarity.

## Tasks

<task id="1">
**Rename RegularForce → RegularCPU**

In `src/profiler.h`, find the TimerID enum and rename:
```cpp
RegularForce,  // → RegularCPU,
```

Also update `getTimerName()` function to return "RegularCPU" for this timer.

Search for any PROFILE_START/STOP calls using TimerID::RegularForce and update them.
</task>

<task id="2">
**Remove completely unused timers**

Remove these TimerIDs that have no instrumentation and are never called:
- IrregularNeighborLoop
- IrregularCMLoop
- IrregularCorrection
- IrregularPredict
- IrregularPairsEvaluated
- WorkerRecvWait
- WorkerTaskDispatch
- WorkerSendComplete
- WorkerIdleTime

Also remove from `getTimerName()` switch statement.
</task>

<task id="3">
**Disable always-zero timers with #ifdef**

Wrap these timers that are always 0 but might be useful later:
- IrregularTotal
- RegularTotal
- RegularMap
- MPIWait
- MPIBarrier
- MPIReduce
- MPIBcast
- MPIWindowSync
- WorkerCompute
- WorkerIdle
- FewBodySearch

Use `#ifdef PROFILER_EXTENDED_TIMERS` to conditionally include them.

Create a reduced TimerID enum with only active timers when PROFILER_EXTENDED_TIMERS is not defined.
</task>

<task id="4">
**Update any call sites**

Search the codebase for any PROFILE_START/STOP calls using removed timers and remove those calls:
- `src/worker_routines.cpp`
- `src/irregular_routines.cpp`
- `src/queue_scheduler.h`
- `src/Particle/compute_acceleration.cpp`
</task>
