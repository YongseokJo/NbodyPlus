## Objective

Add SoA sync calls to `fb_integration.cpp` to ensure particle data consistency during SDAR integration. The main sync needed is for perturber particles that are accessed during force calculation.

## Context

In `Group::ARIntegration()`:
1. CM particle properties are copied from `groupCM` to `sym_int.particles.cm`
2. SDAR integration runs (`sym_int.integrateToTime()`)
3. In `ar_interaction.hpp`, perturber particles are accessed via `particles[pert_adr[j]]`

The perturber access happens inside SDAR's `calcAccPert()` which predicts particle positions.

**Key insight**: `ar_interaction.hpp` uses the global `particles[]` array and `neighbors[]` array directly. We need to sync perturbers from SoA before ARIntegration runs.
