## Objective

Add SoA sync calls to `fb_check.cpp` and verify the complete SDAR compatibility integration through a build test.

## Context

`fb_check.cpp` contains `CheckBreak()` and `CheckBreak2()` functions that check if a binary group should be terminated. These functions access group member positions/velocities which are stored in SDAR's internal `sym_int.particles`.

Since `CheckBreak()` operates on SDAR's internal copies (not the main `particles[]` array), minimal sync is needed. However, we should ensure the check functions have access to current neighbor data if they access perturbers.
