<task id="T3" title="Calculate Amdahl's Law speedup estimates">
<what>
For each potential optimization, calculate expected speedup using Amdahl's Law.
</what>
<how>
Amdahl's Law: Speedup = 1 / (1 - p + p/s)

Where:
- p = fraction of time in optimized component
- s = speedup factor for that component

Calculate for:
1. **MPI Batching (Phase 24)**
   - p = communication fraction
   - s = 2 (assume 50% reduction in MPI time)

2. **Dispatch Pipelining (Phase 25)**
   - p = QueueWait fraction (starvation time)
   - s = 5 (assume 80% elimination of starvation)

3. **Combined (Phases 24+25)**
   - Sequential application of both speedups

Example calculation:
```python
def amdahl(p, s):
    return 1 / (1 - p + p/s)

# If communication = 32%
mpi_speedup = amdahl(0.32, 2)  # → 1.19 (19% faster)

# If starvation = 10%
pipe_speedup = amdahl(0.10, 5)  # → 1.09 (9% faster)

# Combined (conservative: multiply)
combined = mpi_speedup * pipe_speedup  # → 1.30 (30% faster)
```
</how>

<task id="T4" title="Compute variance from multiple runs">
<what>
Use variance runs to estimate measurement uncertainty.
</what>
<how>
```python
import pandas as pd

main = pd.read_csv('.../main/profiling.csv')
var1 = pd.read_csv('.../variance-1/profiling.csv')
var2 = pd.read_csv('.../variance-2/profiling.csv')

# Compare key metrics across runs
# (Note: runs may have different step counts, so compare mean per-interval)
def per_interval_mean(df, col):
    return df[col].mean() * 1e-9  # Convert to seconds

metrics = ['WholeRoutine_ns', 'IrregularForce_ns', 'MPISend_ns']
for m in metrics:
    vals = [per_interval_mean(df, m) for df in [main, var1, var2]]
    print(f"{m}: {vals[0]:.3f}s (var: {min(vals):.3f}-{max(vals):.3f})")
```
