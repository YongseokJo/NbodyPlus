Compute scaling:
```python
import pandas as pd

# Load both datasets
small = pd.read_csv('.../main/profiling.csv')  # ~10K particles
large = pd.read_csv('.../scale-100k-1/profiling.csv')  # 100K particles

# Wall time comparison
small_wall = small['WholeRoutine_ns'].mean() * 1e-9
large_wall = large['WholeRoutine_ns'].mean() * 1e-9

# Scaling factor
particle_ratio = 100000 / 10000  # 10x
time_ratio = large_wall / small_wall

print(f"Particle ratio: {particle_ratio}x")
print(f"Time ratio: {time_ratio:.1f}x")
print(f"Scaling efficiency: {particle_ratio/time_ratio:.2f}")

# For N-body, expect O(N log N) to O(N^2) scaling
# Ideal O(N): time_ratio = particle_ratio
# O(N log N): time_ratio = particle_ratio * log(N_large)/log(N_small)
# O(N^2): time_ratio = particle_ratio^2
```
</how>
