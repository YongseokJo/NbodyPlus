## Objective

Wait for profiling jobs to complete and collect results:
1. Monitor job status until all complete
2. Validate output files exist
3. Copy profiling data to analysis directory
4. Verify data quality (non-zero metrics)

## Context

- Jobs submitted by Plan 23-01
- Run directories: workflow/runs/analysis-100_*, variance-[12]_*
- Expected outputs: profiling.csv, profiling_step_*.json
- Job tracking: .planning/phases/23-deep-analysis/JOBS.md

## Tasks

<task id="T1" title="Check job status">
<what>
Poll SLURM queue until all profiling jobs complete.
</what>
<how>
```bash
# Check all jobs from JOBS.md
squeue -u $USER --format="%.18i %.9P %.30j %.8u %.2t %.10M %.6D %R"

# Or check specific job IDs from JOBS.md
squeue -j <job_id_1>,<job_id_2>,<job_id_3>
```

Repeat until no jobs remain in queue (all completed or failed).
</how>
<done>
- All jobs completed (not in queue)
- Exit codes checked via sacct if needed
</done>
</task>

<task id="T2" title="Verify job success">
<what>
Check that each job completed successfully (not failed/cancelled).
</what>
<how>
```bash
# Check job completion status
sacct -j <job_id> --format=JobID,State,ExitCode

# Or check for output files in run directory
ls workflow/runs/analysis-100_*/output/profiling.csv
ls workflow/runs/variance-1_*/output/profiling.csv
ls workflow/runs/variance-2_*/output/profiling.csv
```
</how>
<done>
- All jobs show COMPLETED state
- Or profiling.csv exists in each run directory
</done>
</task>
