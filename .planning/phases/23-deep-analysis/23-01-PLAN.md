## Objective

1. Main run: 100 steps with current test case
2. Variance run 1: 20 steps
3. Variance run 2: 20 steps

Note: Scaling runs with 100K ICs will be added in Plan 23-02 after user provides ICs.

## Context

- Workflow scripts: `workflow/bin/submit.sh`
- Test config: `tests/test4/config.toml`
- Scheduler: SLURM (from workflow/config.sh)
- Profiling enabled with `--profile` flag

## Tasks

<task id="T1" title="Prepare 100-step config">
<what>
Temporarily modify tests/test4/config.toml to run for 100 output intervals.

Current config has:
- StopTime = 3.0e5 years
- dtOutput = 1.0e5 years (3 outputs)

For 100 outputs, options:
- Option A: StopTime = 1.0e7, dtOutput = 1.0e5 → 100 outputs
- Option B: Keep StopTime, reduce dtOutput to 3.0e3 → 100 outputs

Choose Option A (longer simulation, same interval density).
</what>
<how>
1. Read current tests/test4/config.toml
2. Create a backup: tests/test4/config.toml.bak
3. Modify StopTime to 1.0e7 (10 Myr)
4. Verify dtOutput is 1.0e5 (0.1 Myr)
5. Calculate expected outputs: 10 / 0.1 = 100
</how>
<done>
- config.toml modified with StopTime = 1.0e7
- Backup exists at config.toml.bak
</done>
</task>
