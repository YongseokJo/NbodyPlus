## Goal

Add timing instrumentation to worker_routines.cpp to capture time spent waiting for work (MPI_Recv), executing tasks, and sending completion signals.

## Tasks

<task id="1">
Add new TimerIDs for worker timing

Add to TimerID enum in profiler.h:

```cpp
// Worker-side timers (Phase 8)
WorkerRecvWait,      // Time waiting in MPI_Recv for next task
WorkerTaskDispatch,  // Time executing the assigned task
WorkerSendComplete,  // Time in MPI_Isend + MPI_Wait
WorkerIdleTime,      // Cumulative idle time (recv wait + sync waits)
```

Update `getTimerName()` array accordingly.
</task>

<task id="2">
Instrument MPI_Recv wait time in WorkerRoutines()

Wrap the MPI_Recv call:

```cpp
void WorkerRoutines() {
    // ...
    while (true) {
        PROFILE_START(TimerID::WorkerRecvWait);
        MPI_Recv(&queue, 1, queue_type_mpi, ROOT, QUEUE_TAG, MPI_COMM_WORLD, &status);
        PROFILE_STOP(TimerID::WorkerRecvWait);

        task = queue.task;
        // ...
```

This captures how long workers wait for the next task from root.
</task>

<task id="3">
Instrument task dispatch/execution time

Wrap the switch statement:

```cpp
        PROFILE_START(TimerID::WorkerTaskDispatch);
        switch (task) {
            case TASK_IRR_FORCE:
                // ... existing code ...
                break;
            // ... other cases ...
        }
        PROFILE_STOP(TimerID::WorkerTaskDispatch);
```

This captures the actual compute time per task.
</task>

<task id="4">
Instrument MPI_Isend + Wait completion

Wrap the send/wait at the end of the loop:

```cpp
        PROFILE_START(TimerID::WorkerSendComplete);
        int send_value = ptcl_id;
        if (!(task == TASK_IRR_FORCE || ...))
            send_value = static_cast<int>(task);
        MPI_Isend(&send_value, 1, MPI_INT, ROOT, TERMINATE_TAG, MPI_COMM_WORLD, &request);
        MPI_Wait(&request, &status);
        PROFILE_STOP(TimerID::WorkerSendComplete);
    }
}
```
</task>

<task id="5">
Track cumulative idle time

Add helper to compute idle time:

```cpp
// After each iteration, idle time = recv_wait + any sync waits
// In practice, WorkerRecvWait captures most idle time

// Can add explicit idle tracking if needed:
void Profiler::recordIdleTime(TimerID source_timer) {
    auto& source = stats_[static_cast<int>(source_timer)];
    auto& idle = stats_[static_cast<int>(TimerID::WorkerIdleTime)];
    idle.record(source.last_ns);
}
```

For now, WorkerRecvWait serves as the primary idle metric.
</task>

## Verification

- [ ] WorkerRecvWait captures actual wait time (should be non-zero when workers idle)
- [ ] WorkerTaskDispatch captures task execution (should correlate with task complexity)
- [ ] WorkerSendComplete is small (async send + wait should be fast)
- [ ] Timers work correctly on worker ranks (not just root)
- [ ] No interference with MPI communication

## Must Haves

- Must work on all worker ranks
- Must not interfere with MPI_Recv/Send correctness
- Idle time should be meaningful for load balance analysis
- Works with all task types (IRR_FORCE, REG_FORCE, etc.)
