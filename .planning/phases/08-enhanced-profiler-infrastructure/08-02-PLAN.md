## Goal

Add histogram support to capture call-time distributions, enabling identification of outliers and understanding of timing variability.

## Tasks

<task id="1">
Add Histogram class to profiler.h

Create a lightweight histogram implementation with logarithmic buckets:

```cpp
class Histogram {
public:
    static constexpr int NUM_BUCKETS = 20;
    // Buckets: <1us, 1-10us, 10-100us, 100us-1ms, 1-10ms, 10-100ms, 100ms-1s, >1s
    // Using log10 scale for better resolution

    void record(long long duration_ns);
    void reset();
    void merge(const Histogram& other);

    // Output
    void print(std::ostream& os) const;
    std::string toJSON() const;

    // Statistics
    long long getPercentile(double p) const;  // p in [0,1]
    long long getMedian() const { return getPercentile(0.5); }

private:
    long long buckets_[NUM_BUCKETS] = {0};
    long long total_count_ = 0;

    int getBucketIndex(long long ns) const;
    std::pair<long long, long long> getBucketRange(int idx) const;
};
```
</task>

<task id="2">
Add histogram storage to TimerStats

Add optional histogram to TimerStats (disabled by default to save memory):

```cpp
struct TimerStats {
    // ... existing fields ...

    std::unique_ptr<Histogram> histogram;

    void enableHistogram() {
        if (!histogram) histogram = std::make_unique<Histogram>();
    }

    void recordWithHistogram(long long duration_ns) {
        record(duration_ns);
        if (histogram) histogram->record(duration_ns);
    }
};
```
</task>
