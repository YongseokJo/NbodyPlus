## Goal

Add per-rank statistics collection and MPI aggregation to the profiler, enabling min/avg/max timing across all MPI ranks plus load balance metrics.

## Tasks

<task id="1">
Add MPI aggregation data structure to profiler.h

Add a new struct `AggregatedStats` that holds min/avg/max values:

```cpp
struct AggregatedStats {
    double min_seconds;
    double max_seconds;
    double avg_seconds;
    double total_seconds;
    long long min_count;
    long long max_count;
    long long total_count;
    int min_rank;
    int max_rank;
};
```
</task>

<task id="2">
Add MPI aggregation method to Profiler class

Add method `aggregateAcrossRanks()` that:
1. Gathers interval stats from all ranks using MPI_Reduce
2. Computes min/max/avg for each timer
3. Stores results in a vector of AggregatedStats
4. Tracks which rank had min/max for load balance analysis

```cpp
void aggregateAcrossRanks(MPI_Comm comm);
```

Use MPI_MINLOC and MPI_MAXLOC to also capture which rank has min/max.
</task>

<task id="3">
Add load balance metrics calculation

Add method to compute load balance ratio (max/avg) for key timers:

```cpp
double getLoadBalanceRatio(TimerID id) const;
```

A ratio > 1.2 indicates significant imbalance.
</task>

<task id="4">
Add throughput tracking

Add fields to TimerStats for work counting:

```cpp
long long work_units = 0;  // e.g., particles or pairs
long long interval_work_units = 0;

double throughputPerSecond() const {
    return interval_total_ns > 0 ?
           interval_work_units * 1e9 / interval_total_ns : 0.0;
}
```

Add method to record work:
```cpp
void recordWork(TimerID id, long long units);
```
</task>

<task id="5">
Add aggregated output methods

Add `printAggregatedSummary()` that outputs:
- Per-timer breakdown with min/avg/max across ranks
- Load balance ratios for key timers
- Throughput metrics where work units recorded

Format similar to existing `printIntervalSummary()` but with rank columns.
</task>

<task id="6">
Add PROFILE_WORK macro

```cpp
#ifdef PERFORMANCETRACE
#define PROFILE_WORK(timer_id, units) Profiler::instance().recordWork(timer_id, units)
#else
#define PROFILE_WORK(timer_id, units) ((void)0)
#endif
```
</task>

## Verification

- [ ] Code compiles with MPI enabled
- [ ] `aggregateAcrossRanks()` produces valid min/avg/max values
- [ ] Load balance ratio calculated correctly (manual test with known imbalanced workload)
- [ ] Throughput metrics work when work units recorded
- [ ] No MPI deadlocks or hangs

## Must Haves

- MPI_Reduce used for aggregation (not MPI_Gather to avoid memory issues with many ranks)
- Thread-safe if OpenMP enabled in future
- Zero overhead when PERFORMANCETRACE not defined
