<task type="auto">
  <name>Task 2: Implement mcluster_runner.cpp</name>
  <files>src/mcluster_runner.cpp</files>
  <action>
Create implementation file with:

1. Includes:
   - `"mcluster_runner.h"`
   - `<unistd.h>` (fork, exec, pipe, dup2)
   - `<sys/wait.h>` (waitpid, WEXITSTATUS)
   - `<sys/stat.h>` (stat for file validation)
   - `<fstream>` (file I/O for transformation)
   - `<sstream>` (string building)
   - `<iostream>` (error output)
   - `<iomanip>` (setprecision for output)
   - `<cstring>` (strerror)

2. buildMclusterArgs(const MclusterConfig& config):
   - Build vector of argument strings
   - If config.M > 0: add "-M" and M value (M takes precedence per Phase 26 decision)
   - Else: add "-N" and N value
   - Add: -P (profile), -R (radius), -f (IMF), -Z (metallicity), -b (binary), -e (epoch)
   - Add output format flags: "-C", "3" (table format), "-u", "1" (astrophysical units)
   - Add output filename: "-o", MCLUSTER_OUTPUT_BASE
   - Return vector

3. runMclusterSubprocess(binary_path, args):
   - Create pipes for stdout and stderr capture
   - fork() to create child process
   - In child: redirect stdout/stderr to pipes, execv() the binary
   - In parent: read from pipes, waitpid() for completion
   - Return RunResult with exit_code, captured output, success flag
   - Handle errors: pipe creation failure, fork failure, exec failure (exit 127)
   - Use a 4096-byte buffer for reading

4. validateMclusterOutput(output_file, expected_count):
   - Use stat() to check file exists
   - Check file size > 0
   - Open file, check first line contains "#Mass" header
   - Count data lines (non-empty, non-comment)
   - If expected_count > 0, verify line count matches
   - Print diagnostic: "McLuster generated N stars"
   - Return true on success, false with error message on failure

5. transformMclusterOutput(mcluster_file, abyss_file):
   - McLuster format: mass x y z vx vy vz [extras...]
   - ABYSS format: x y z vx vy vz mass
   - Open input file, create output file
   - Skip header lines (starting with #)
   - For each data line: parse mass, x, y, z, vx, vy, vz
   - Write in ABYSS order with scientific notation, 8 decimal places
   - Close files, return success/failure
  </action>
