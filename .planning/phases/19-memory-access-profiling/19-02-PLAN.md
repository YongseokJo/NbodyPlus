## Objective

Add cache counter instrumentation around the force calculation loop to measure L1D and LL cache miss rates during neighbor pair evaluation.

## Requirements Addressed
- MEM-01: Measure L1/L2/L3 cache miss rates in force loops

## Tasks

<task id="1" type="code">
In irregular_routines.cpp, add cache counter initialization at start of irregular force calculation.

Find the start of computeIrregularForce function (look for PROFILE_START(TimerID::IrregularForce)):
```cpp
void ABYSS::computeIrregularForce() {
    PROFILE_START(TimerID::IrregularForce);
```

Add after PROFILE_START:
```cpp
    // Phase 19: Initialize cache counters on first call
    static bool cache_init_done = false;
    if (!cache_init_done) {
        PROFILE_CACHE_INIT();
        cache_init_done = true;
    }
```
</task>

<task id="2" type="code">
In compute_acceleration.cpp, wrap the main neighbor loop with cache measurement.

Find the start of the neighbor loop (around line 110, after the CMPtclsSet setup):
```cpp

	AccumulatorSoA acc;
```

Add before this line:
```cpp
	// Phase 19: Start cache counters for neighbor loop
	auto cache_start = std::chrono::high_resolution_clock::now();
	PROFILE_CACHE_START();

```

Find the end of the neighbor loop, where the acceleration is applied (look for the end of the for loop that iterates over neighbors, around line 200, before the 4th order correction):
```cpp
	} // end neighbor loop

	// Calculate the 4th order irregular acceleration from neighbors
```

Add between the loop end and the correction:
```cpp

	// Phase 19: Stop cache counters after neighbor loop
	auto cache_end = std::chrono::high_resolution_clock::now();
	double cache_elapsed_s = std::chrono::duration<double>(cache_end - cache_start).count();
	PROFILE_CACHE_STOP(cache_elapsed_s);

```
</task>
