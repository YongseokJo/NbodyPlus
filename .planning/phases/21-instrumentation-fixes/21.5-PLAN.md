# Phase 21.5: Profiler Aggregation Redesign

**Created:** 2026-01-19
**Goal:** Fix MPI aggregation to use point-to-point communication instead of collective operations

## Problem

The current `aggregateFromWorkers()` uses `MPI_Reduce` which requires ALL ranks to call it together. But:
- Root runs in `root_routines.cpp`
- Workers run in `worker_routines.cpp`
- No shared synchronization point exists

Result: Deadlock when `USE_MPI` is enabled.

## Solution Design

Use the existing task dispatch mechanism to request profiling data from workers:

```
1. Root sends TASK_SEND_PROFILING to all workers
2. Workers pack their profiling stats into a struct
3. Workers send struct to root via MPI_Send
4. Root collects via MPI_Recv from each worker
5. Root aggregates the data
```

## Implementation Plan

### Step 1: Add Task Type (queue.h)

```cpp
// Add new task type
TASK_SEND_PROFILING = 40,  // Request workers to send profiling data
```

### Step 2: Define Transfer Struct (profiler.h)

```cpp
// Struct to transfer profiling data from workers to root
struct ProfilerTransferData {
    // Neighbor stats
    long long neighbor_count;
    long long neighbor_min;
    long long neighbor_max;
    double neighbor_mean;
    long long neighbor_histogram[15];

    // Particle type stats
    long long regular_count;
    long long cm_count;
    long long regular_time_ns;
    long long cm_time_ns;

    // Worker compute time (this worker's data)
    long long compute_time_ns;
    int worker_rank;
};
```

### Step 3: Worker Handler (worker_routines.cpp)

```cpp
case TASK_SEND_PROFILING:
    {
        auto& prof = Profiler::instance();
        ProfilerTransferData data = prof.packTransferData(my_rank);
        MPI_Send(&data, sizeof(data), MPI_BYTE, ROOT, PROFILING_TAG, MPI_COMM_WORLD);
    }
    break;
```

### Step 4: Root Collection (root_routines.cpp)

Before output:
```cpp
// Request profiling data from all workers
Queue profiling_request = {TASK_SEND_PROFILING, -1, 0.0};
for (int w = 1; w <= num_workers; w++) {
    MPI_Send(&profiling_request, 1, queue_type_mpi, w, QUEUE_TAG, MPI_COMM_WORLD);
}

// Collect responses
std::vector<ProfilerTransferData> worker_data(num_workers);
for (int w = 1; w <= num_workers; w++) {
    MPI_Recv(&worker_data[w-1], sizeof(ProfilerTransferData), MPI_BYTE,
             w, PROFILING_TAG, MPI_COMM_WORLD, MPI_STATUS_IGNORE);
}

// Aggregate
profiler().aggregateFromTransferData(worker_data);
```

### Step 5: Aggregation Function (profiler.h)

```cpp
void aggregateFromTransferData(const std::vector<ProfilerTransferData>& worker_data) {
    // Sum neighbor counts
    aggregated_neighbor_count_ = 0;
    aggregated_neighbor_min_ = LLONG_MAX;
    aggregated_neighbor_max_ = 0;
    // ... aggregate all fields
    neighbor_data_aggregated_ = true;
}
```

## Files to Modify

1. `src/queue.h` - Add TASK_SEND_PROFILING
2. `src/profiler.h` - Add ProfilerTransferData struct, packTransferData(), aggregateFromTransferData()
3. `src/worker_routines.cpp` - Handle TASK_SEND_PROFILING
4. `src/root_routines.cpp` - Request and collect profiling data before output
5. `src/global.h` - Add PROFILING_TAG constant

## Success Criteria

1. No deadlock when profiling is enabled
2. neighbor_profiling.count > 0 in JSON output
3. particle_type_breakdown.regular_count > 0 in JSON output
4. worker_distribution.compute_time shows non-zero values
5. Simulation completes correctly with energy conservation

## Risk Mitigation

- Test incrementally: first just the message passing, then the aggregation
