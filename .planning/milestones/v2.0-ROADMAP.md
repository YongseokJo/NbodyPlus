### Phase 9: Profile & Analyze

**Goal:** Collect profiling data from representative simulations and identify the primary bottleneck with quantitative evidence.

**Depends on:** Phase 8 complete

**Plans:** 2 plans

- [x] 09-01: Run profiled simulation (human execution)
- [x] 09-02: Analyze profiling data and identify bottleneck

**Key Findings:**
- Primary bottleneck: IrregularForce at 53.5% of wall time
- Irregular forces evaluated ~122x more frequently than regular forces
- Optimization targets: force loop vectorization, MPI batching

**Completed:** 2026-01-17 (2 plans in 2 waves)

### Phase 10: Targeted Optimization

**Goal:** Implement optimization for the identified bottleneck and validate with before/after comparison.

**Depends on:** Phase 9 complete (bottleneck identified)

**Plans:** 3 plans

- [x] 10-01: Create AVX-512 vectorized force kernel module
- [x] 10-02: Integrate vectorized kernel into compute_acceleration.cpp
- [x] 10-03: Validation and profiling comparison

**Optimization Implemented:**
- AVX-512 vectorization of irregular force neighbor loop
- Pre-gather pattern for aligned SIMD access
- Newton-Raphson refinement for double precision rsqrt

**Results:**
- IrregularForce: 69.5s → 67.3s (-3.2%)
- Wall time: 130s → 126.4s (-2.8%)
- Energy conservation: dE/E0 = 1.34e-6 (PASS)

**Completed:** 2026-01-18 (3 plans in 2 waves)

## Milestone Summary

**Key Decisions:**

| Decision | Rationale | Outcome |
|----------|-----------|---------|
| Pre-gather for SIMD | Align scattered neighbor data before vectorized compute | ⚠ Gather overhead limits gains |
| AVX-512 vectorization | Target IrregularForce bottleneck with SIMD | ⚠ 3.2% gain vs 20% target |
| Explicit AVX-512 flags | `-march=native` insufficient on login node | ✓ Required for compilation |

**Issues Resolved:**

- Identified IrregularForce as primary bottleneck (was unknown before profiling)
- Quantified irregular vs regular force call ratio (122:1)
- Validated energy conservation after optimization

**Issues Deferred:**

- MPI batching (reduce ~105M messages/interval)
- SIMD gather intrinsics (avoid pre-gather copies)
- GPU irregular forces kernel

**Technical Debt Incurred:**

- AVX-512 requires Skylake-AVX512 or later (no fallback path)
- Pre-gather pattern adds memory copy overhead
