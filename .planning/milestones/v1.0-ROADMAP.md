# Milestone v1.0: AoS to SoA Conversion

**Status:** ✅ SHIPPED 2026-01-17
**Phases:** 1-7
**Total Plans:** 28

## Overview

Complete conversion of ABYSS particle data structures from Array of Structures (AoS) to Structure of Arrays (SoA) layout, maintaining full simulation correctness. Energy conservation validated against baseline. No performance improvement observed (bottleneck elsewhere).

## Milestone Summary

**Key Decisions:**
- Full SoA (not hybrid) — Cleaner architecture
- Accessor functions — Encapsulation for future changes
- 66 MPI_Win objects — One per SoA array
- Exit-only sync for SDAR — Keep Group using AoS, sync on exit
- GPU bridge pattern — AoS↔SoA conversion at transfer boundaries

**Issues Resolved:**
- MPI window count verified (66 windows work without performance issues)
- SDAR compatibility maintained without modifying SDAR library
- Energy conservation verified (better than baseline)

**Technical Debt Incurred:**
- No performance improvement — bottleneck not in memory layout
- Future work: Profile to identify actual bottleneck (GPU compute? MPI?)
