## Phase 24: MPI Message Batching

**Goal:** Reduce MPI message count by batching multiple particle tasks per message

**Requirements:**

| ID | Requirement | Description |
|----|-------------|-------------|
| BATCH-01 | Implement configurable batch size | Default: 10-100 particles |
| BATCH-02 | Modify root dispatch | Accumulate tasks before sending |
| BATCH-03 | Modify worker receive | Process batched tasks |
| BATCH-04 | Profile and tune | Find optimal batch size |

**Success Criteria:**
1. Message count reduced from 25M to 2.5M-250K per interval
2. No increase in starvation events
3. Energy conservation unchanged
4. Net speedup of 10-20%

---

## Phase 25: Dispatch Pipelining

**Goal:** Hide dispatch latency by prefetching next task

**Requirements:**

| ID | Requirement | Description |
|----|-------------|-------------|
| PIPE-01 | Double-buffering on worker | Current + next task |
| PIPE-02 | Prefetch from root | Send next before current completes |
| PIPE-03 | Edge case handling | Last task, completion |

**Success Criteria:**
1. Workers never wait for task (steady state)
2. Additional 5-10% speedup on top of batching

**Dependencies:** Phase 24 (batching provides foundation)
